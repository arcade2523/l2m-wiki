리니지2M을 하면서 직접 실험하고 정리한 내용을 한곳에 모으려고 사이트를 만들었습니다.
앞으로 새 공략은 이 **공략** 탭에 올립니다.

## 메뉴 안내

| 메뉴 | 볼 수 있는 것 |
|---|---|
| 처음 시작 | 입문했을 때 무엇부터 하면 좋은지 순서대로 정리한 안내 |
| 공략 | 이 사이트에 직접 쓰는 새 공략 |
| 블로그 게시글 | 티스토리 블로그에 올렸던 실험, 사냥터 정보, 클래스 분석 글 |
| 연금술 | 일반·상급 연금의 단계별, 슬롯별 확률표 |
| 영상 | 유튜브 오락실 채널의 최신 영상 |
| 거래소, 혈맹 모집 | 장비 거래 글과 혈맹 모집 글 |

## 예전 글은 어디에 있나요

티스토리 블로그의 리니지2M 글은 [블로그 게시글](../blog/index.html) 탭에서 그대로 볼 수 있습니다.
블로그도 계속 열려 있습니다.
